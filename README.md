
# 🤖 AI Personal Assistant

A simple AI-powered personal assistant built using Python, Flask, and Google's Gemini API.

### Features
- AI-powered question answering
- Email summarization
- Gemini API integration
- Interactive web interface(haven't deployed due to limitation of api key)

### Tech Stack
Python | Flask | Google Gemini API | HTML | CSS | JavaScript

### Development Timeline
Started in **Starting of the year 2026** as a learning project while exploring Python backend development, Flask, and AI API integration.

### Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Gemini API key to `.env`.
4. Run: `python main.py`
